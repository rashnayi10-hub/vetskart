# VetsKart | On-Demand Veterinary Home-Visit Platform

## Project Overview

VetsKart is an on-demand veterinary service platform designed to connect pet owners with veterinary professionals for convenient home-based pet healthcare services.

**Live Website:** https://www.vetskart.com/

This repository showcases a portfolio demonstration of the data engineering workflows supporting veterinary appointment requests, location-based provider matching, and appointment coordination. It uses synthetic data and is separate from VetsKart's live production backend.

## Business Problem

Pet owners may face difficulties accessing veterinary care due to transportation limitations, pet mobility issues, or the availability of nearby veterinarians.

VetsKart helps simplify veterinary service requests by connecting pet owners with eligible service providers in their geographic area.

## Data Engineering Implementation

- Developed **Python-based data ingestion pipelines** to process veterinary service requests and veterinarian information.
- Implemented **data validation and transformation** to improve data consistency and reliability.
- Used **SQL and SQLite** to store and process appointment and veterinarian assignment information.
- Developed **location-based matching logic** to identify eligible veterinarians based on service area and availability.
- Implemented automated tests to validate data processing and matching workflows.

## Technologies Used

**Python | SQL | SQLite | ETL | Data Validation | Git | GitHub**

## Data Pipeline Architecture

Pet Owner Requests → Data Ingestion → Validation → Location-Based Matching → Appointment Assignment → Database Storage → Operational Reporting

## Project Impact

- Supported efficient processing of veterinary home-visit requests.
- Demonstrated automated location-based veterinarian matching.
- Improved visibility into appointment assignment and service availability.
